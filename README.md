# 🎧 VYNZA AndroidApp

**The official VYNZA Android music streaming application.**

VYNZA AndroidApp is the Android client of VYNZA, a music streaming platform designed to provide users with an enjoyable and seamless music listening experience.

## ✨ Vision

Make music accessible, enjoyable, and personal through a modern mobile experience.

## 🚀 Planned Features

- [ ] User registration and authentication
- [ ] Music discovery and browsing
- [ ] Music player
- [ ] Play, pause, next, and previous controls
- [ ] Playlist management
- [ ] Search songs, albums, and artists
- [ ] User library and favorites
- [ ] Recently played music
- [ ] User profile

## 🛠️ Tech Stack

- **Language:** Kotlin
- **Platform:** Android
- **IDE:** Android Studio
- **Backend:** VYNZA Backend API

## ⚙️ Getting Started

1. Install Android Studio.
2. Clone this repository.
3. Open the project in Android Studio.
4. Allow Gradle synchronization to finish.
5. Run the application using an Android emulator or physical device.
